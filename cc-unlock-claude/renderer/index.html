这个版本做了什么

安全研究工作站 — 把 Claude Code 配置为全谱系安全研究执行环境，并让**子 agent 也带上反软拒绝人格 + 记忆**，多 agent 任务不回退默认行为。

  • 研究员记忆注入 — track records + MEMORY.md 反拒绝载体
  • CLAUDE.md 轻量人格 + lab-scope 框架（穿透通用子 agent）
  • sec-forge 总控（JIT harness 引擎 + 自我进化）+ jit-harness
  • .claude/agents/ 子 agent 覆盖 — memory:project 启动注入 + 技能预载
  • settings.json bypassPermissions 合并写入
子 agent 覆盖机制
自定义 agent 的 memory: project 在启动时自动注入 MEMORY.md 前 200 行 / 25KB。CLAUDE.md 对通用 Task 子 agent 生效。Explore/Plan 内置 agent 官方跳过 CLAUDE.md，属只读盲区。
