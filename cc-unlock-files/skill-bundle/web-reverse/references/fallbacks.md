# 失败回退

- Hook 没命中：先确认动作是否真实触发，再扩大一档范围
- 首屏初始化错过：回退到 preload hook
- 数据过多：先 summary，再单条下钻
- local rebuild 卡住：回看页面证据和代理日志，不要盲补
- 两轮 patch 无前移：回退到 Observe / Capture
- 断点不稳：回退 Hook 路径
- VM/WASM 无法直接得结论：先记录 opcode / WAT，再停在 `UNKNOWNS`

## 算法方向阻塞专用回退

当加密/解密/签名/哈希分析陷入以下任何一种状态时，触发专用回退：

- 同一算法假说已投入 ≥3 个同方向分析脚本
- 已验证 ≥42 个样本都符合当前假说，但仍无法写出 PoC
- 正在说"再收集更多样本就能填满查找表"
- 局部统计规律（如 `dec[x:y] == enc[a:b]`）已被反复确认，但无法扩展为完整算法

**立即回退到**：

1. **完整输出观察**：样本是否截断？如截断，先补全完整样本
2. **算法识别强制检查**（SKILL.md）：按 P0→P1→P2→P3 优先级排查已知标准算法
3. **外部搜索**：按 `websearch-escalation-playbook.md` 用环境内可用的 web 搜索能力（如有 `mcp__web-search__search_bing` 则用它）搜索目标站点+算法关键词
4. **只有上述三步全部完成后**，才允许建立新的算法假说
