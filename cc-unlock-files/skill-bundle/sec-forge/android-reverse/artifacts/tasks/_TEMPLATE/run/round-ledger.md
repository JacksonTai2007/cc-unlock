# Round Ledger（每轮分析追加，不覆盖旧记录）

> 本文件按分析轮次追加，记录每轮的分析路径，让后续接手者能复现。原则：边分析边写，不等结束后凭记忆补；不覆盖旧轮次；不丢失失败轮次。与 `report.md` 的区别：report.md 是面向用户的阶段性/最终汇总，round-ledger 是逐轮操作台账。
