# Case Safety Policy

- 仅处理用户明确授权或训练/CTF/样本环境中的目标
- 不主动执行未授权漏洞利用、持久化、投递、横向移动
- 任何会改写真实主机、真实驱动加载状态或真实账号态的动作，都必须先记录风险点

## 动态执行强制暂停

以下操作在自动推进模式下必须写入 `pauseCategory=risk` 并等待用户确认后才能继续，不得仅记录风险点就自动执行：

- 运行未知样本或未确认安全的可执行文件（包括 CreateProcess、ShellExecute 等）
- 向真实进程注入代码或远程线程（包括 Frida attach 到非分析 VM 进程）
- 加载未签名的内核驱动
- 修改真实注册表启动项、服务配置或计划任务
- 对真实网络目标发起连接（非 mock/loopback）

静态分析、只读内存读取、PE 结构解析、字符串提取等只读操作不触发此暂停（但 attach/debugger attach 本身仍受上述规则约束）。

隔离分析 VM 内的操作（快照可回滚）可以降低暂停要求，但必须在 report.md 中注明 VM 环境和快照点。
