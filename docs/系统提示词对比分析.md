# v2.4-alpha 指令入口对比

| 项目 | v2.3 实验模式 | v2.4 当前模式 |
|---|---|---|
| Claude 客户端 | companion 原生/自定义模式 | 原版 Claude Desktop |
| 主指令 | 可选客户端 systemPrompt 替换 | 工作区 CLAUDE.md |
| 全局 Claude settings | legacy 脚本可能写入 | 不管理 |
| Claude memory/agents/rules/agent-memory | legacy 部署支持 | 不再部署 |
| Codex memory/rollout | 支持注入和卸载 | 不再注入或删除 |
| 技能 | sec-forge | sec-forge |
| 个人数据 | 旧入口部分按名称处理 | 不依据名称自动删除 |

`prompt_snapshot.systemPrompt` 记录客户端提供的系统指令；`CLAUDE.md` 可能在另一类工作区指令事件中记录。两个入口不同。模型不会因为读取 CLAUDE.md 就自行设置客户端的系统提示词。

只能依据当前会话的实际加载记录和请求结果描述效果。不得根据历史快照或文件哈希断言服务端永远不会拒绝。
