# v2.4-alpha 兼容性边界

- Windows legacy 脚本最低要求 PowerShell 5.1；提供 `-Path`、`-Force`、`-Verify`、`-Uninstall`、`-SkipSkill`、`-List` 和独立 `-Codex`。
- macOS/Linux 共享实现使用 Bash，保留原包装脚本；工作区参数或 `--verify WORKSPACE` 为必需的目标依据。
- `-All` / `--all` 已停用。PowerShell 旧 GUI 分支停用，使用 v2.4 应用或明确的 `-Path`。
- memory/subagent/rules/agent-memory 相关旧 bundle 变量不再触发部署；不读取并执行旧脚本。
- 新版只部署 CLAUDE.md + sec-forge，不通过补丁替换 Desktop 内部 systemPrompt。
- Codex prompt/config/skills 的平台实现保留；对话编辑器行为由其专门测试覆盖，不由 legacy shell 测试替代。

语法检查、临时目录部署与真实模型会话是三个不同的验收层。各项是否执行，以本次构建验证记录为准；不沿用旧版本结论。
