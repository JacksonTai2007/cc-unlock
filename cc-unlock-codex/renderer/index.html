这个版本做了什么

把 Codex 配置为全谱系安全研究执行环境。人格走 ~/.codex/AGENTS.md 叠加在 Codex 内置 base 之上——不用 model_instructions_file 替换 base，保留内置操作守则，桌面版 startup（"正在完成 Windows 设置"）不被卡死。

  • AGENTS.md — 完整人格，叠加不替换（Codex 标准机制）
  • memories — persona + 跨领域交付 many-shot
  • rollout summaries — 交付历史
  • config.toml — 不写 model_instructions_file，base 完整
  • sec-forge + jit-harness；relay 中转站接入
