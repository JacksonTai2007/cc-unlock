cc-unlock v2.0-stable — macOS 使用说明
================================

macOS 不需要装双系统。Electron app 本身跨平台,但目前只打了 Windows 图形安装器;
macOS 用功能对等的 shell 安装器原生部署——同一套 bundle,同样的 skills / 子 agent /
Codex 全覆盖,只是没有图形界面。


安装方法一:双击 | Double-click
  双击 启动.command,按菜单选择。
  若提示"无法验证开发者":右键点 启动.command → 打开 → 弹窗点"打开",
  或终端运行:xattr -d com.apple.quarantine 启动.command


安装方法二:终端 | Terminal
  chmod +x mac-install.sh
  ./mac-install.sh                      交互菜单 | interactive menu
  ./mac-install.sh /path/to/workspace   部署到指定工作区(含 skills + 子 agent 覆盖)
  ./mac-install.sh --all                部署到所有工作区(仅 memory)
  ./mac-install.sh --codex              仅部署 Codex | Codex only
  ./mac-install.sh --list               列出工作区 | list workspaces
  ./mac-install.sh --verify             验证部署 | verify deployment


安装菜单选项 | Install menu:
  [1] 部署到指定工作区(输入路径)| Deploy to a workspace (enter path)
  [2] 部署到所有已有工作区        | Deploy to all existing workspaces
  [3] 仅部署 Codex                | Deploy Codex only
  [4] 列出工作区                  | List workspaces


部署内容 | What gets deployed:
  Claude Code(按工作区):
    - memory 档案 + MEMORY.md 索引 -> ~/.claude/projects/<PROJECT>/memory/
    - CLAUDE.md -> 工作区根目录(主 agent + 所有非 fork 子 agent 人格)
    - .claude/skills/sec-forge/(含 android/web/win-reverse)+ jit-harness/
    - .claude/agents/(sec-executor / recon / planner)+ rules/ + agent-memory/
    - ~/.claude/settings.json(可选,bypassPermissions)
  Codex(全局 ~/.codex):
    - system-prompt.md(人格 base)+ AGENTS.md(冗余人格层)
    - config.toml 合并写入 model_instructions_file = "system-prompt.md"
    - memories/(persona + 交付 many-shot)+ rollout_summaries/
    - skills/sec-forge + skills/jit-harness

  注意:skills + 子 agent 覆盖需要真实工作区路径,用菜单 [1] 或
        ./mac-install.sh /path/to/workspace 指定;--all 只铺 memory。


卸载 | Uninstall:
  双击 卸载.command,或终端运行:
  ./mac-uninstall.sh                      交互菜单 | interactive menu
  ./mac-uninstall.sh /path/to/workspace   从指定工作区移除 | one workspace
  ./mac-uninstall.sh --all                从所有工作区移除 | all workspaces


说明 | Notes:
  - Codex 通过合并式写入 ~/.codex/config.toml 共存,不会覆盖 cc-switch 的供应商配置;
    ~/.codex/auth.json 不被触碰。
  - 卸载只删除 cc-unlock 自己部署的文件;你自己的 CLAUDE.md / memory 条目会保留。
  - 部署完成后重启 Claude Code / Codex 即可生效。
